Fonts and Characters

A UI Font asset bakes the characters a game needs from a font file into a distance-field atlas. Only the baked characters can draw. A character the atlas does not have draws as a box, and the Text Fit panel lists it. This page covers choosing what is baked, and drawing languages that one font file does not cover.

Which characters are baked

The atlas holds the union of:

  • the ranges that are switched on: Latin (on by default), LatinExtended, Greek, Cyrillic;
  • with StringTableCharacters (on by default), every character the project's string tables use, in every language. The tables are the .txt files of the folders in <project>/Localization; their keys are not counted;
  • the CustomCharacters text.

With StringTableCharacters on, editing a string table re-bakes the font, so a new translation's characters are in the atlas without listing them. Turn it off for a font that only draws fixed texts, such as a number font, to keep its atlas small.

Fallback fonts

A font file rarely covers every script. FallbackFonts lists further font files that are tried, in order, for each character the font file has no glyph for: a Latin display face first, a Japanese face behind it. Every character is baked from the first file that has it, at the same base size, into the same atlas. The line height and baseline come from the font file. Kerning applies between two characters from the same file.

  1. Open the UI Font asset.
  2. Add the fallback font files to Fallback Fonts (.ttf, .otf or .ttc; a collection bakes its first face).
  3. Transform the font. Characters that none of the files have are counted in a warning, and still draw as boxes.
Atlas size
A CJK language can add thousands of characters. The atlas grows up to 8192 × 8192; a font whose characters do not fit fails to transform. Lower the base size, or split rarely used texts into another font.

Fixing missing characters

In the UI Document editor, the Text Fit panel shows "N characters missing from Font" while the previewed language uses characters the font has not baked. Add characters on that row adds them, and every character of the previewed language's string tables, to the font's Custom Characters, then saves and re-bakes the font. If the font file and its fallbacks do not have a glyph for a character, adding it does not help: add a fallback font that does.
