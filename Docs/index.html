Game UI

Game UI draws menus, HUDs and in-world screens from UI Document assets. A document is a tree of elements (panels, texts, buttons, sliders, lists, vector shapes) placed by anchors and offsets, styled by UI Style assets, drawn with UI Font assets, and bound to blackboard entries for live data. A UI Canvas component shows a document over the screen or on a panel in the world. The runtime is part of the engine; the plasma.gameui package adds the editors.
