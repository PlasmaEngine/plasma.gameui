Text and Brush Effects

Text elements can have an outline and a soft drop shadow. Panels, buttons and every other element with a brush can have angled and radial gradients with any number of colour stops, and can blur the scene behind them. Vector shapes can have holes and an outline stroke. All of these are drawn by the UI shaders in one pass, with no extra textures.

Text outline and shadow

Outline and shadow come from the font's distance field, so they stay sharp at any size. The outline grows outward from the glyph edge by OutlineWidth pixels. The shadow is the glyph drawn behind it, offset by ShadowOffset and blurred by ShadowSoftness. A shadow colour with zero alpha, the default, turns the shadow off.

PropertyDefaultDescription

Note
The reach of an outline and a shadow is limited by the font's distance field, which spans 16 px at the font's base size. At large font sizes the limit grows with the size.

Gradients

GradientMode picks the gradient. Horizontal and Vertical blend Color into GradientColor. Angled and Radial use the GradientStops: each stop has a Position from 0 to 1 and a colour. Without stops they blend Color into GradientColor.

  • Angled runs the stops along GradientAngle: 0° is left to right, 90° top to bottom.
  • Radial runs them from the rect's centre (0) to its edge (1), as an ellipse that fits the rect.

Gradients follow the brush's rounded corners and are tinted by the element's state colour and opacity. Styles can set gradient stops and an angle too. The inspector shows Gradient Color with any gradient, the stops with Angled and Radial, and the angle with Angled only.

Backdrop Blur

BackdropBlur blurs the scene behind an element's shape by about that many pixels, for frosted glass panels. The element's own fill draws over the blur, so a fill colour with partial alpha tints the glass.

  • Only screen-space canvases blur. Other UI drawn on the same canvas is not part of the blurred image: the blur shows the scene, not the UI under the element.
  • The view computes the blur only while at least one element on screen asks for it. It costs a chain of downsampling passes, starting at half the view's resolution.
  • Rendering.GuiBackdropBlur 0 turns the blur off; elements then draw without it.

Vector shapes

A Vector Shape's PathData uses SVG path syntax. Every subpath with three or more points is filled. FillRule decides how subpaths combine:

Fill ruleResult
Separate ShapesEach subpath is filled on its own.
Even-Odd (Holes)A point is filled when it lies inside an odd number of subpaths, so a subpath inside another cuts a hole: the inside of a ring, the counter of a letter.

StrokeWidth above 0 draws an outline of that width along every subpath in StrokeColor, over the fill. Subpaths closed with Z get a closed outline.
